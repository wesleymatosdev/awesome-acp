# Contributing to Awesome ACP

Thank you for wanting to contribute!

## How to add a resource

1. Check that the resource is not already listed.
2. Make sure the link works and points directly to the resource.
3. Add it under the appropriate section, alphabetically ordered.
4. Use this entry format:

```markdown
- [Resource Name](https://example.com) - One-sentence description without marketing language.
```

5. Open a pull request with a short description of what you are adding and why.

## Quality bar

- Resources must be relevant to the Agent Client Protocol (ACP).
- Descriptions are one plain sentence: what it is, not why it's great.
- No dead links, no affiliate links, no promotional entries.

## Guidelines

By participating you agree to abide by the [Code of Conduct](CODE_OF_CONDUCT.md).
