# Awesome ACP [![Awesome](https://awesome.re/badge.svg)](https://awesome.re)

> Curated resources for the [Agent Client Protocol](https://agentclientprotocol.com) (ACP) — the standard that lets any ACP-compatible editor talk to any ACP-compatible coding agent.

## Official documentation

- [Agent Client Protocol — Introduction](https://agentclientprotocol.com/get-started/introduction) - The protocol's official documentation and starting point.

## Agents

Coding agents and harnesses that implement ACP, following the [official agents directory](https://agentclientprotocol.com/get-started/agents). Descriptions state how each one exposes ACP.

- [AgentPool](https://phil65.github.io/agentpool/advanced/acp-integration/) - Agent Client Protocol integration for desktop applications.
- [Augment Code](https://docs.augmentcode.com/cli/acp) - Auggie CLI acts as an ACP agent for any compatible client.
- [AutoDev](https://github.com/phodal/auto-dev) - Multi-agent coding development platform built on Kotlin Multiplatform.
- [Blackbox AI](https://docs.blackbox.ai/features/blackbox-cli/introduction) - Blackbox CLI runs as an ACP agent in compatible editors.
- [Bub](https://github.com/bubbuild/bub-contrib/tree/main/packages/bub-acp-server) - ACP server package for the Bub agent runtime.
- [Claude Agent](https://github.com/zed-industries/claude-agent-acp) - Adapter that drives the Claude Agent SDK from any ACP client.
- [Claw Orchestrator](https://github.com/Enderfga/claw-orchestrator/blob/main/skills/references/acp.md) - Cross-engine fan-out runtime that also exposes itself as an ACP agent.
- [Cline](https://cline.bot/) - Open-source AI coding agent with ACP support.
- [Codex CLI](https://github.com/agentclientprotocol/codex-acp) - ACP server that exposes OpenAI Codex CLI functionality to clients and IDEs.
- [Code Assistant](https://github.com/stippi/code-assistant) - LLM-powered autonomous coding assistant with an ACP mode.
- [Construct](https://github.com/construct-worlds/construct) - Terminal-native agentic development environment with an ACP server.
- [crow-cli](https://crow-ai.dev) - Stateful ACP-native coding agent with shared memory and orchestration.
- [Cursor CLI](https://cursor.com/docs/cli/acp) - Cursor CLI's `agent acp` mode runs it as a protocol server for custom clients.
- [Docker cagent](https://github.com/docker/cagent) - AI agent builder and runtime from Docker Engineering.
- [fast-agent](https://fast-agent.ai/acp/) - Agent framework with ACP support for editor integration.
- [Factory Droid](https://factory.ai/) - Coding agents for coding, testing, and deployment workflows.
- [fount](https://github.com/steve02081504/fount) - Agent runtime that exposes ACP connectivity.
- [Gemini CLI](https://github.com/google-gemini/gemini-cli) - Open-source AI agent that brings Gemini into the terminal with native ACP support.
- [GitHub Copilot CLI](https://docs.github.com/en/copilot/reference/acp-server) - Copilot CLI's Agent Client Protocol server.
- [Goose](https://goose-docs.ai/docs/gdk/acp/) - Block's open-source agent, usable as an ACP agent over stdio, HTTP, or WebSocket.
- [Hermes Agent](https://hermes-agent.nousresearch.com/docs/user-guide/features/acp) - Agent that runs inside ACP-compatible editors and collaboration platforms.
- [Junie](https://junie.jetbrains.com) - JetBrains' AI coding agent.
- [Kaagum](https://git.systemreboot.net/kaagum/about/) - Tiny, security-focused AI agent written in Guile.
- [Kimi Code CLI](https://github.com/MoonshotAI/kimi-code) - CLI agent whose `kimi acp` subcommand serves ACP clients such as Zed and JetBrains IDEs.
- [Kiro CLI](https://kiro.dev/docs/cli/acp/) - Runs Kiro as an ACP agent in JetBrains IDEs, Zed, and other compatible editors.
- [localharness](https://github.com/compusophy/localharness) - Self-directed agent harness with ACP support.
- [Minion Code](https://github.com/femto/minion-code) - Implementation of Claude Code with ACP connectivity.
- [Mistral Vibe](https://github.com/mistralai/mistral-vibe) - Minimal CLI coding agent by Mistral.
- [Muse Spark Code](https://github.com/RandyNorthrup/muse-spark-code/blob/main/docs/acp.md) - Unofficial agent that brings Meta's Muse Spark to editors over ACP.
- [OpenClaw](https://docs.openclaw.ai/cli/acp) - ACP bridge for IDE integrations.
- [OpenCode](https://github.com/sst/opencode) - Open-source coding agent with ACP support.
- [OpenHands](https://docs.openhands.dev/openhands/usage/cli/ide/overview) - Use OpenHands in code editors through the Agent Client Protocol.
- [Pi](https://github.com/svkozak/pi-acp) - ACP adapter for the pi coding agent.
- [Poolside](https://github.com/poolsideai/pool) - Coding agent that runs in the terminal or any ACP-compatible editor.
- [Qoder CLI](https://docs.qoder.com/cli/acp) - Qoder CLI's ACP mode.
- [Qwen Code](https://github.com/QwenLM/qwen-code) - Open-source AI coding agent that lives in the terminal.
- [Raven](https://evermind-ai.github.io/Raven/agent-protocols/) - Agent supporting ACP among its agent protocols.
- [Raxol](https://github.com/DROOdotFOO/raxol/blob/master/docs/features/CODING_AGENT.md) - Elixir terminal that embeds a coding agent over ACP.
- [siGit Code](https://github.com/getsigit/sigit) - Modular local-inference LLM coding agent.
- [Stakpak](https://github.com/stakpak/agent) - Open-source agent that lives on your machines and keeps apps running.
- [stdio Bus](https://github.com/stdiobus/stdiobus) - Agentic process supervisor and NDJSON JSON-RPC message router with session-based routing.
- [VT Code](https://github.com/vinhnx/vtcode) - Open-source Rust terminal coding agent with ACP support.
